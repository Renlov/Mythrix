# 12. Локальное тестирование промпта (до Android)

Прогнать `dm_system_v1.txt` на Qwen 2.5 1.5B локально на маке через
Ollama. Цель — увидеть качество ответов и поправить промпт до того,
как писать Android-код.

## Установка (один раз)

```bash
brew install ollama
ollama serve &              # держать в отдельном терминале
ollama pull qwen2.5:1.5b    # ~1 ГБ
```

## Запуск

```bash
python3 scripts/test_dm.py --player Кейн
```

Игра идёт в терминале. Пиши действия — DM отвечает. `/exit` — выход,
`/reset` — очистить историю.

## Что проверять

| Проверка | Как |
|---|---|
| Атмосфера держится | После 5-7 ходов DM всё ещё пишет в somber-тоне, не скатывается в «привет, искатель приключений!» |
| Формат не ломается | Каждый ответ содержит `[NARRATIVE]` и `[EVENTS]` блоки, JSON валиден |
| Никаких чисел | DM не пишет HP, цены, броски, расстояния |
| Не выдумывает | Не появляются NPC/предметы вне Библии Мира |
| Прогресс квеста не озвучивается | DM не пишет «Стадия 1 завершена» |
| По имени, на «ты» | Все обращения корректные |
| Подвод работает | После разговоров с шахтёрами и воинами игрок чувствует мотивацию идти на дракона |

## Полезные тестовые ходы

Прогнать как минимум:

1. `Открываю дверь и вхожу внутрь` — проверка открытия сцены
2. `Подхожу к трактирщику. Заказываю эль и спрашиваю, что тут случилось` — диалог
3. `Сажусь к шахтёрам и спрашиваю, отчего такие хмурые` — горюющие NPC
4. `Спрашиваю воинов, куда они собираются` — обречённые NPC
5. `Не видел ли кто здесь молодую женщину? Сестру мою, Айну. Она проходила полгода назад` — главный квест
6. `Покупаю короткий лук` — intent `buy`
7. `Бью трактирщика ножом` — стресс-тест (mood должен переключиться, intent attack)
8. `Иду к воинам и говорю — возьмите меня с собой` — целевой триггер пилота

## Известные проблемы Qwen 2.5 1.5B

- JSON ломается ~30% случаев — пока тестируем без авто-парсинга,
  на Android будет валидация + retry.
- Иногда выдаёт ответ на английском — увеличить «по-русски» в промпте
  или добавить first-message system reminder.
- Иногда забывает формат после 10+ ходов — это сигнал для саммаризации
  (которая будет в Android-коде).

## Когда промпт можно считать готовым к коду

- 8 из 10 ответов сохраняют формат
- Атмосфера держится все 10 ходов
- DM ни разу не выдумал внеканонный факт
- Хотя бы один прогон закончился тем, что игрок САМ предложил идти с воинами

Если хуже — правим `dm_system_v1.txt`, прогоняем заново.
Только когда зелёный свет — начинаем Android-код.

## Печать собранного промпта

Для отладки можно посмотреть, что именно отправляется в модель:

```bash
python3 scripts/test_dm.py --show-system > /tmp/prompt.txt
```

Полезно проверить размер: `wc -w /tmp/prompt.txt`.
