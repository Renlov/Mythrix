# 07. Сбор датасета для будущего fine-tune

## Принятая стратегия — Гибрид (Источники 1 + 2)

Финальная пропорция датасета:
- **~60% синтетика** от старшей модели (Qwen 72B)
- **~30% реальные логи** живых сессий пользователей
- **~10% ручной эталон** для критичных паттернов

## Источник 1: реальные логи (органика)

С первого дня промптинг-фазы включаем логирование. Хранить:
- полный собранный промпт (system + context + action)
- ответ модели целиком
- флаг «JSON валиден»
- флаг «игрок перезапросил/продолжил»
- метаданные сцены

Таблица `training_log` в SQLite, отдельно от игровой БД.

## Источник 2: синтетика от Qwen 72B

Запускается параллельно промптинг-фазе. Старшая модель играет за DM,
скрипт играет за игрока (или мы вручную) на нашей Библии Мира.

- Лицензия Qwen 72B — **Apache 2.0**, обучать на выводах можно.
- Целевой объём для холодного старта: **500-1000 примеров**.
- Покрытие сценариев: бой, диалог, исследование, торговля, скрытность.

**НЕ использовать** для синтетики выводы Claude/GPT — их ToS формально
запрещает обучение публикуемых моделей.

## Источник 3: ручной эталон

50-100 примеров, написанных руками для критичных паттернов:
- бой (двухфазный ход)
- передача предметов
- конец сцены с `scene_ended=true` + хорошее саммари
- обработка нестандартных действий игрока

## Что НЕ брать

### YouTube-сессии DnD (Critical Role и аналоги)
- Diarization путает голоса 4-6 спикеров → дорогая ручная чистка.
- Не наш формат — нужна конвертация через старшую модель (+шум).
- **Загрязняют каноны** — Эксандрия в нашу Драконью Башню.
- Английский язык (мы делаем русскую игру).

Допустимо: брать **только как стилевой референс** для few-shot в системном
промпте и для генератора синтетики («пиши в стиле Мерсера»).

### Литературный корпус (Сапковский/Аберкромби)
Может пригодиться как **опциональный базовый fine-tune для голоса**,
один раз, до основного. Не приоритет.

## Формат записи примера

```json
{
  "input": {
    "system_prompt": "...",
    "player": {...},
    "current_scene": {...},
    "active_quests": [...],
    "relevant_memory": [...],
    "scene_summary": "...",
    "recent_messages": [...],
    "player_action": "Атакую Орма луком"
  },
  "output": {
    "narrative": "Ты вскидываешь лук...",
    "events": {
      "intents": [{"type": "attack", ...}],
      "scene_ended": false
    }
  },
  "meta": {
    "source": "synthetic_qwen72b | real_log | manual",
    "scenario_type": "combat | dialogue | exploration | trade",
    "quality_score": 1-5,
    "language": "ru"
  }
}
```

`meta.scenario_type` критичен для балансировки. Если в датасете 80%
диалогов и 5% боёв — модель будет плохо вести бои.

## Опт-ин и приватность

- Пользователь явно соглашается на использование сессий для обучения.
- Без согласия — логи только локально, для пользователя.
- При экспорте: имена персонажей игрока заменяются плейсхолдерами.
