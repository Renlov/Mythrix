# 08. Решения по пилоту Mythrix

Зафиксированные решения по стартовой реализации ИИ-DM.

## Язык

**Русский.** Вся Библия Мира, системный промпт, нарратив, синтетика —
на русском. Английские источники (Critical Role и т.п.) использовать
только как стилевой референс, без прямого попадания в датасет.

## Целевая модель — DeepSeek (облако)

**Решение (2026-05-23):** локальная модель убрана из проекта. DM работает
на **облачной модели DeepSeek** через `DeepSeekLlmEngine` (OpenAI-совместимый
стриминг). Прежний план on-device Qwen 2.5 0.5B/1.5B и fine-tune (LoRA)
отменён — `ModelDownloader` в основной ветке не используется.

Следствия:
- большое контекстное окно → агрессивная экономия не нужна; контекст всё
  равно режется реляционно (RAG, см. `02`), но ради чистоты, не лимита;
- формат `[NARRATIVE] + [EVENTS]` модель держит надёжно, но **валидация +
  один retry** при невалидном `[EVENTS]` реализованы как страховка
  (`ChatViewModel.streamOnce` + проверка `EventParser`);
- fine-tune/сбор датасета под локальную модель более не приоритет.

## Стартовый сеттинг для пилота — Таверна

Существующий Dragon Tower **на время пилота не используется** —
делаем изолированную тестовую среду «Таверна».

### Локация
**`loc_tavern_starting`** — единственная локация в пилоте.
Атмосфера: печальная, в воздухе веет смертью. Дракон разрушил
окрестности, продовольствия мало, таверна скоро закрывается.

### NPC (5 шт.)

1. **Трактирщик** (`npc_tavern_innkeeper`) — торговец.
   Инвентарь: меч, щит, лук, топор, припасы для восстановления HP.
   Подзывает героя при входе: «Что тебе, путник? Мы скоро закрываемся,
   дракон разрушил все продовольствия и у нас не так много припасов».

2. **Шахтёр 1** (`npc_miner_1`) — пустой взгляд, выпивает, тихо говорит
   с шахтёром 2 про дракона, который убил их жён, пока они были в шахтах.
   Не агрессивен, делится горем если спросить.

3. **Шахтёр 2** (`npc_miner_2`) — то же состояние, дополняет шахтёра 1.

4. **Воин 1** (`npc_warrior_1`) — при оружии, ждёт часа выступить
   против дракона. Понимает, что идёт на верную смерть. Хмурый,
   немногословный, может присоединиться к мотивации героя.

5. **Воин 2** (`npc_warrior_2`) — аналогично, дополняет воина 1.

### Сюжетная задача пилота
Через диалоги с NPC у героя должна **сформироваться мотивация**
победить дракона. Это и есть тест: умеет ли DM подвести игрока к
эмоциональному решению через атмосферу и реплики NPC, не диктуя
ему действия.

## Что тестируем на пилоте

1. **Удержание канонов.** DM не выдумывает 6-го NPC, 3-го воина,
   не предлагает «эльфа в углу».
2. **Удержание атмосферы.** Каждая реплика поддерживает «веет смертью»,
   не скатывается в стандартное «привет, искатель приключений!».
3. **Формат вывода.** Сколько раз из 100 ходов JSON валиден с первого
   раза, сколько — после retry, сколько — провал.
4. **Двухфазный бой.** Если игрок задирается на воинов — корректно ли
   проходит attack-intent → расчёт → описание исхода.
5. **Граница сцены.** Срабатывает ли `scene_ended=true` при выходе
   из таверны (когда игрок решит идти к дракону).

## Текущее состояние реализации (2026-05-21)

Пилот вышел за рамки «одной локации» — реализовано:

- **Игровое состояние** (`PlayerState` + `GameStateRepository`, сохранение
  в файл): hp, gold, инвентарь, экипировка (1 предмет на слот, `damage_die` /
  `armor_bonus`), стадии квестов, текущая локация.
- **События DM** применяются движком (`EventApplier`): покупка/передача/
  выброс предметов, `quest_advance`, `location_change`. Купленный предмет
  переходит к игроку и вырезается из инвентаря торговца в контексте DM.
- **Карта и переходы** (`location_change`, только по связям):
  Таверна ↔ Деревня ↔ Заваленные шахты ↔ Северный лес → (отрог — не построен).
  Контекст промпта переключается по локации: `[LOCATION]` + `[ВЫХОДЫ]` +
  `[NPCS]` только присутствующих.
- **UI:** лист персонажа (фото/класс/HP/золото, инвентарь-пейджер по
  категориям, надевание галочкой), магазин по слову-ссылке «Магазин»,
  меню действий + раздел «Зацепки», баннер целей (пара за раз).
- **Цели пилота** (детерминированные триггеры): узнать про Айну → купить
  оружие → узнать опасность на севере → решить идти с воинами.

## Что отложено за пределы пилота

- Полная Библия Мира Dragon Tower.
- Векторизация и RAG (на пилоте достаточно жёсткого фильтра —
  всё помещается в окно 32k).
- Сбор реальных логов (только синтетика + ручные тесты).

## Стилевые референсы для системного промпта

Выбраны три референса, закрывающие нужную шкалу стиля:

1. **Мэтт Мерсер (Critical Role)** — техническая структура открытия
   сцены. Сцена всегда открывается тремя сенсорными якорями до
   появления NPC: звук → запах → свет/температура → потом люди.
   В промпт: «открывай сцену тремя сенсорными деталями перед первым
   действием или репликой NPC».

2. **Бреннан Ли Маллиган (Dimension 20 / Worlds Beyond Number)** —
   мастер пауз и недосказанности. NPC обрывают реплику, отворачиваются,
   отвечают одним словом — пауза несёт больше, чем монолог.
   В промпт: «NPC чаще молчат, отворачиваются или отвечают обрывисто,
   чем произносят полные фразы. Недосказанность сильнее экспозиции».

3. **Кормак Маккарти (Кровавый меридиан, Дорога)** — рубленые
   предложения, никаких эмоциональных эпитетов, ровная интонация —
   и это и есть ужас. Пейзаж и насилие описываются с одинаковым
   равнодушием.
   В промпт: «не использовать оценочные эпитеты (страшный, ужасный,
   печальный). Пусть факт сам несёт вес. Короткие предложения».

Эти три цитаты пойдут как часть few-shot в системном промпте DM.
Дополнительно: фрагменты диалогов из русскоязычных источников
(aternia.games/materials, RPG-Zone.ru, Imaginaria.ru) добавляются
как примеры именно русскоязычного DM-стиля — выбираются пользователем
после парсинга.
