# 09. Каталог атмосфер (mood)

Закрытый список значений `locations.atmosphere.mood`. Используется
сборщиком контекста для подбора few-shot примеров из `few_shots/<mood>/`.

**Правило различения:** mood определяется по **состоянию игрока в сцене**,
а не по сюжетной важности или общему тону мира.

## 7 значений

### `cheerful`
**Когда:** праздник, ярмарка, тёплая встреча, победа, искреннее веселье.
**Критерий:** люди смеются, шумят, никто не боится.
**Сенсорика:** музыка, яркий свет, запахи еды и напитков, тепло.

### `neutral`
**Когда:** обычная бытовая сцена — рынок днём, путь по дороге, ремесленник
за работой. Ничего не происходит, ничего не давит.
**Критерий:** ни тревоги, ни радости. Дефолт.
**Сенсорика:** ровные звуки рутины.

### `tense`
**Когда:** ожидание чего-то нехорошего, переговоры на грани, скрытое
наблюдение, преследование без атаки.
**Критерий:** угрозы пока нет, но игрок насторожён, рука у меча.
**Сенсорика:** тишина там, где должен быть шум; взгляды; пауза перед словом.

### `somber`
**Когда:** горе, утрата, предчувствие беды, безнадёжность. Поминки,
разговор с горюющим, выход на палубу под крик капитана в тумане.
**Критерий:** угроза предчувствуется, но НЕ материализована. Преобладает
эмоция, не действие.
**Сенсорика:** тусклый свет, приглушённые звуки, тяжёлый воздух.

### `dangerous`
**Когда:** бой, погоня, противник виден и действует, обвал, пожар,
загнан в угол.
**Критерий:** угроза **осязаема и адресна**, игрок реагирует на неё
прямо сейчас.
**Сенсорика:** резкие звуки, движение, физический контакт.

### `mysterious`
**Когда:** загадка, странность, потустороннее. Древняя руина, заброшенный
храм, NPC говорит на неизвестном языке, предмет ведёт себя не как должен.
**Критерий:** игрок не понимает, **что** перед ним. Не страх, а
недоумение и любопытство.
**Сенсорика:** необъяснимые детали, нарушение ожиданий, симметрии.

### `sacred`
**Когда:** торжественный обряд, святое место, клятва, погребение,
аудиенция у высокой персоны.
**Критерий:** требуется уважение, шум неуместен.
**Сенсорика:** свечи, благовония, эхо, ровная речь.

## Разрешение конфликтов

Если сцена подходит под несколько mood — берётся **доминирующий по
действию игрока**:

| Ситуация | mood |
|---|---|
| Похороны, и игрок видит убийцу в толпе | `sacred` (пока не действует) |
| Игрок прыгает на убийцу с криком | `dangerous` |
| Таверна, оплакивают погибших, в углу подозрительный незнакомец | `somber` |
| Тот же незнакомец достал нож | `dangerous` |
| Игрок входит в храм после боя, ещё в крови | `sacred` (mood локации побеждает остаточный) |

## Динамика внутри сцены

Mood локации — **статический дефолт**. Динамическое изменение
происходит через event `atmosphere_shift` (см. `04-event-extraction.md`):

```
[EVENTS]
{
  "intents": [...],
  "atmosphere_shift": "dangerous"
}
```

Android временно переопределяет mood до конца сцены (или до следующего
`atmosphere_shift`). После выхода игрока из локации mood сбрасывается
к дефолту из `locations.json`.

## Минимум для пилота (таверна)

Достаточно покрыть 4 mood, чтобы протестировать механику переключения:

| mood | Где встретится в пилоте |
|---|---|
| `somber` | дефолт таверны |
| `tense` | если игрок задирается на воинов |
| `dangerous` | если игрок ударил кого-то / начался бой |
| `cheerful` | для контраста, как контрольная проверка: попросить DM описать ту же таверну в другую ночь (тест на «не нагнетает ли везде») |

Остальные 3 mood (`neutral`, `mysterious`, `sacred`) — оставляем
библиотеку пустой, добавим примеры когда понадобятся.

## Минимальная библиотека few-shot

Для пилота нужно **2 фрагмента на каждый из 4 mood = 8 эталонов**.
Уже есть:
- `somber/` — Фрагмент 1 (трюм), Фрагмент 5 (шторм)

Остальные 6 нужно собрать (см. план в `08-project-decisions.md`).
