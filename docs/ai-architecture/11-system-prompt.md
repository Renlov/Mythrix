# 11. Системный промпт DM v1

Файл: [game/src/main/assets/prompts/dm_system_v1.txt](../../game/src/main/assets/prompts/dm_system_v1.txt)

## Структура

Промпт состоит из 7 секций + 4 эталонных примера:

1. **Роль** — кто такой DM, на каком языке, в каком жанре.
2. **Главные правила** — 7 жёстких запретов/требований.
3. **Длина и форма** — короткий абзац, вопрос только когда пасует.
4. **Стиль** — три референса (Маккарти / Брennan / Мерсер).
5. **Формат ответа** — `[NARRATIVE] + [EVENTS]`.
6. **Типы intents** — 7 операций, которые DM может инициировать.
7. **Атмосфера** — поддержка mood, `atmosphere_shift`.
8. **Эталоны** (few-shot) — 4 примера на пилотной таверне.

## Динамические плейсхолдеры

- `{{player_name}}` — заменяется на имя из создания персонажа.

Динамическая часть (мир, история, ход игрока) приклеивается **после**
системного промпта сборщиком контекста — см. `02-context-assembler.md`.

## Размер

~1200 токенов для Qwen 2.5 1.5B. В пределах целевого лимита (см. `06-training-strategy.md`).

## Версионирование

Файл назван `dm_system_v1.txt`. Изменения:
- Мелкие правки формулировок — правим в том же файле.
- Структурные изменения (новый intent, новая секция) — создаём `_v2.txt`,
  старая остаётся для откатов и сравнения качества.
