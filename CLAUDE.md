# Mythrix — инструкции для Claude

## ИИ-DM архитектура

При любой работе над ИИ-частью приложения (системный промпт, Библия Мира,
сборщик контекста, парсер событий) — **сначала прочитай и
соблюдай** документы в [docs/ai-architecture/](docs/ai-architecture/).

Краткие принципы:
- DM использует только факты из Библии Мира, не выдумывает сущности
- Все числа (HP, броски, урон, цены) считает Android, не модель
- Формат ответа DM: `[NARRATIVE]` + `[EVENTS]` (JSON по схеме); при невалидном
  `[EVENTS]` — один retry с напоминанием формата
- `player.json` — корень контекста; в промпт подаётся не вся Библия Мира, а
  релевантное сцене (реляционный RAG, см. `02-context-assembler.md`)
- DM работает на **облачной модели DeepSeek** (`DeepSeekLlmEngine`).
  Локальная модель (Qwen/on-device) и fine-tune из проекта убраны.

См. [docs/ai-architecture/README.md](docs/ai-architecture/README.md) для индекса.

## Стартовый сеттинг для тестов ИИ

Пилот ведётся на изолированной локации **Таверна** (см. `08-project-decisions.md`),
а не на существующем Dragon Tower. Dragon Tower не трогаем до конца пилотной фазы.

## Язык

## Git-воркфлоу

- Ветки именуются `mythrix-N` (порядковый номер задачи).
- Никаких следов AI в коммитах (без Co-Authored-By, без «🤖 Generated with»).
- Локальная работа в worktree; в конце задачи коммит локально и удаление
  worktree. Пушит и мерджит пользователь сам.
