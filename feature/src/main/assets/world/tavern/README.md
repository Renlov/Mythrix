# Библия Мира пилота — Таверна «Последний привал»

Изолированная стартовая сцена для тестирования ИИ-DM.
Соответствует схеме [docs/ai-architecture/01-world-bible-schema.md](../../../../../../docs/ai-architecture/01-world-bible-schema.md).

## Файлы

- `locations.json` — 1 локация (таверна, mood=somber)
- `npcs.json` — 5 NPC (трактирщик + 2 шахтёра + 2 воина)
- `items.json` — 6 предметов (нож игрока + 5 у трактирщика на продажу)
- `quests.json` — 1 квест с 4 стадиями (от входа до решения присоединиться к воинам)
- `player.json` — Кейн, странник 1 ур.

## Сюжетная задача пилота

Главная цель игрока — **найти сестру Айну** (`quest_find_aina`),
которая полгода назад ушла из родного города по этой дороге к
неизвестному возлюбленному. Айна — рана игрока, не загадка с
разгадкой: NPC отвечают тенями и неопределённостями, прямого
ответа не существует.

Из основной цели должно прорасти **вторичное решение** —
присоединиться к Кеттилю и Гриму в походе на дракона
(`quest_slay_dragon`). Решение должно созреть через атмосферу
таверны и истории NPC, **не подсказываемое напрямую**.
Прохождение пилота = игрок САМ предложил идти с воинами.

Имя героя выбирается игроком при создании персонажа. В JSON-ах
и системном промпте используется плейсхолдер `{{player_name}}`.

## Что тестируем

| Тест | Ожидание |
|---|---|
| DM не выдумывает 6-го NPC | В сцене ровно 5 персонажей |
| DM не предлагает товаров вне списка | Только меч/щит/лук/топор/припасы |
| Цены не выдумываются | Берутся из items.json, считаются Android |
| Атмосфера держится | Каждый ход поддерживает somber, никаких "привет, искатель приключений!" |
| Подвод к решению работает | После 3-5 разговоров игрок САМ хочет идти на дракона |

## Что DM может (и должен) делать

- Описывать сенсорику локации (свет, тени, запах прогоревшего очага)
- Передавать характеры NPC через жесты, паузы, обрывистые реплики
- Связывать истории NPC с backstory Кейна (Айна, сестра)
- Реагировать на нестандартные действия (например, если игрок украл припасы)

## Чего DM делать НЕ должен

- Произносить мотивацию игрока за него
- Называть числа (HP, цены, шансы) — это делает Android
- Объявлять прогресс квеста ("Квест: узнать о драконе — выполнено")
- Выдумывать новых NPC, локации, предметы
- Скатываться в "стандартный фэнтези-DM": бодрый тон, восклицания, прямые подсказки
